# COMP-1327 Banking Chatbot with Functions and Unit Testing Assignment

## Description

In this project, I am demonstrating my understanding of:

- **Functions**: Creating reusable functions for banking tasks.
- **User Input Validation**: Ensuring account numbers, tasks, and
deposit amounts are valid.
- **Exception Handling**: Using 'try-except' blocks to handle errors
like invalid input types or missing accounts.
- **Unit Testing**: Writing and running tests to verify each function
works as expected.
- **Mocking**: Using mock objects to simulate user input during testing.
- **Version Control**: Using Git to track changes and manage project
versions.
